# Panoptic-SLAM Offloading

This repository contains my academic and engineering work on
offloading panoptic segmentation for SLAM systems.

## Key Contributions
- Offline panoptic preprocessing pipeline
- JSON-based panoptic integration
- Custom RGB/RGB-D dataset support
- VM ↔ WSL execution separation
- Robust mask handling and tracking

## Disclaimer
This project is derived from and inspired by prior open-source SLAM
research. Significant architectural and implementation changes were
made for academic experimentation and system offloading.

This repository is **not an official distribution** of the original work.
